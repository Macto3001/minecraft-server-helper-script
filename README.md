# minecraft server helper script
this is a collection of script made for help managing minecraft server

## feature:
- paper serverjar downloader
- paper serverjar autoupdater(need upgrade)
- modrinth project downloader
- modrinth project autoupdater(still in work)
- eula acceptor
- auto backup maker
- offline to online uuid transformer(not out yet)
- super server launch script(experimental)
